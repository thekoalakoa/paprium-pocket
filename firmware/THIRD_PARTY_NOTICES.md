This is the firmware for the Paprium cart's chip, the way the Analogue Pocket core runs it. We release it as
**Little-Man Firmware** (trademark pending), in the file `little_man_firmware.bin`. Version 1.0 comes with the 0.3.0
core. Our team wrote it from our own study of how the cart behaves.

It's free software under the GNU General Public License, version 3 or (at your option) any later version
(GPL-3.0-or-later). See [LICENSE](LICENSE).

Copyright (C) 2026 Marsupial Solutions LLC, for the code written in this folder. The projects it builds on keep their own
copyright. Some of them are under licences that ask for their copyright notice and licence text to travel with the source
and with every binary, so those notices are below.

The firmware file holds the code the cart's chip runs in this core, its work RAM and our MegaWire code, all built from
this tree. So it carries the code listed here, and the same notices cover it. The file isn't signed and isn't encrypted.

From the 0.3.0 release on, this folder is published as `firmware/` in the paprium-pocket repository. The design docs that

## Not in this tree

- **The game.** None of it is here. You need your own copy, and the firmware reads what it needs from it on your Pocket.
- **The CPU MATE brain.** It's a reverse-engineered emulation of the game's CPU partner. The build links it in from
  outside this tree, checked by its hash, and the firmware file carries it. It isn't a third-party open-source
  component, and none of these notices covers it.

## Credits and history

These folks are credited for their history of use, including for parts this firmware doesn't carry anymore.

- **krikzz (mega-ppm).** The firmware in 0.1 through 0.2.6 was built from mega-ppm. Whatever this folder still keeps from
  it is in the mega-ppm row above, under his BSD-3 notice. The first-level door fix (object 107) was his. 0.3.0 builds
  sprites with the cart's own attribute rule, so that fix isn't compiled in anymore.
- **Genesis Plus GX** (<https://github.com/ekeeke/Genesis-Plus-GX>, Eke-Eke and contributors; its Paprium support,
  `cart_hw/paprium.h`, is headed Project Little Man). The 0.2.6 firmware's LZO decoder, in `legacy/026/mame.c`, was
  ported from Genesis Plus GX's Paprium support (`paprium.h`). It's kept as source for the 0.2.6 build and isn't in the
  firmware file. Genesis Plus GX is also an emulator our tests use.
- **TheHpman.** mega-ppm's `mame.c` says it's based on TheHpman's MAME Paprium work (`rom.cpp` in TheHpman's MAME fork).
- **Rockbox.** The WavPack files came to us through the Rockbox project's copy of Conifer Software's decoder, and every
  one of them keeps Conifer's BSD header.
- **MisterPezz82** reported the door fix and shipped it in his MiSTer core.
- **mega-ppm's `sfx.c`** (in `interim/album/`, not in the firmware file) says it's based on libretro.

And thanks to Project Little Man, TheHpman (MAME Paprium research), MAVProxyUser (Genesis Plus GX Paprium work) and the
whole Paprium preservation community.
