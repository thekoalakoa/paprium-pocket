# The core bitstream is not in this folder

`paprium.rbf_r` is the compiled FPGA bitstream. It is a **build artefact**, about
2 MB, regenerated by every build — so it is deliberately excluded from git
(`.gitignore`, `pkg/pocket/Cores/*/*.rbf_r`) rather than committed on every change.

**To install the core**, download `openfpga-Paprium_<version>.zip` from the
[latest release](https://github.com/thekoalakoa/paprium-pocket/releases/latest).
The zip contains this folder *with* the bitstream, plus the platform entry and the
asset directories, laid out for the root of your SD card.

**To build it yourself**, see the Building section of the top-level README. The
bitstream lands here, and `scripts/deploy_to_sd.sh` copies it to the card.

The JSON files beside this one are the core's metadata — how it appears in the
Pocket's menu, its controls, video and audio settings. They are committed because
they are source, not output.
